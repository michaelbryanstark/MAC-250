# TEAM NETFLIX
### We created this app to highlight what we have learned about database structure this semester and how to implement it in an app that everyone is very familiar with!

    python3 netflix_app.py          # then open http://127.0.0.1:5001



- Mock streaming site using Python, flask, sqlite, dbBrowser and SQL!
- API from TMDB (https://www.themoviedb.org) to populate movie and tv posters.
> [!NOTE]  
  > Must create an account at TMDB and generate an API Key
  
  1. Make a free account at https://www.themoviedb.org and create an API key (Settings > API, the "API Key (v3 auth)" value).
  2. Run: TMDB_API_KEY=your_key python3 fetch_posters.py (Windows PowerShell:  $env:TMDB_API_KEY="your_key"; python fetch_posters.py)
